# Pubudini Rathnayake — Personal Portfolio

Personal developer portfolio showcasing my AI, NLP, and Full-Stack engineering work — built with **Next.js 16**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Tech Stack
- **Framework:** Next.js 16 (App Router + Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion

## Getting Started

```bash
git clone https://github.com/pubudini-rathnayake/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
